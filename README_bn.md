# এমসিপি (MCP) ভিত্তিক এআই ভয়েস চ্যাটবট

( [English](README.md) | [中文](README_zh.md) | [日本語](README_ja.md) | বাংলা )

## পরিচিতি

XiaoZhi (শাওঝি) এআই চ্যাটবট হলো একটি উন্মুক্ত উৎসের (Open Source) হার্ডওয়্যার এআই ভয়েস অ্যাসিস্ট্যান্ট, যা Qwen, DeepSeek ইত্যাদির মতো আধুনিক লার্জ ল্যাঙ্গুয়েজ মডেলের (LLM) ক্ষমতাকে বাস্তব হার্ডওয়্যারে রূপান্তর করে। এটি **MCP (Model Context Protocol)** ব্যবহার করে বাস্তব জগতের ডিভাইস ও স্মার্ট হোম নিয়ন্ত্রণ করতে পারে।

এই কাস্টম সংস্করণে বিশেষভাবে যুক্ত করা হয়েছে:
- **ব্রেডবোর্ড ডিআইওয়াই (DIY) বিল্ড সাপোর্ট** (`bread-compact-wifi`)।
- **বাংলা ভাষা ও ব্যাকরণ সহায়তা (bn-BD)** এবং ইউনিকোড স্ক্রিন টেক্সটের জন্য লাইভ **বাংলিশ (Banglish) ট্রান্সলিটারেশন** ইঞ্জিন।
- **মোচি (Mochi) অ্যানিমেটেড ফেস এক্সপ্রেশন** এবং আপগ্রেডেড স্ট্যাটাস বার।

## মূল বৈশিষ্ট্যসমূহ

- **ইন্টারনেট সংযোগ:** Wi-Fi / ML307 Cat.1 4G
- **অফলাইন ভয়েস ওয়েক-আপ:** [ESP-SR](https://github.com/espressif/esp-sr) এর মাধ্যমে তাৎক্ষণিক জাগরণ
- **কমিউনিকেশন প্রোটোকল:** দ্বিমুখী [ওয়েবসকেট (WebSocket)](docs/websocket.md) অথবা MQTT+UDP
- **অডিও কোডেক:** হাই-কোয়ালিটি OPUS অডিও কম্প্রেশন
- **এআই ভয়েস পাইপলাইন:** স্ট্রিমিং ASR (স্পিচ-টু-টেক্সট) + LLM + TTS (টেক্সট-টু-স্পিচ)
- **ডিসপ্লে সমর্থন:** I2C OLED (SSD1306 / SH1106) এবং LCD/TFT ডিসপ্লে
- **ইমোজি ও অ্যানিমেশন:** ইন্টারঅ্যাক্টিভ মুখমণ্ডলের অভিব্যক্তি (Mochi Face Animations)
- **মাল্টি-ল্যাঙ্গুয়েজ সাপোর্ট:** বাংলা, ইংরেজি, চীনা, জাপানি
- **ডিভাইস-সাইড MCP:** স্পিকার, এলইডি, লাইট, রিলে, সারভো এবং সাধারণ GPIO নিয়ন্ত্রণ
- **ক্লাউড-সাইড MCP:** স্মার্ট হোম কন্ট্রোল, ওয়েব সার্চ, ইমেইল ইত্যাদি

## হার্ডওয়্যার ও ব্রেডবোর্ড ডিআইওয়াই (DIY) গাইড

আপনি খুব সহজেই সাধারণ ব্রেডবোর্ডে জাম্পার ওয়্যার দিয়ে নিজের এআই অ্যাসিস্ট্যান্ট তৈরি করতে পারেন:

👉 **[বিস্তারিত ব্রেডবোর্ড ওয়ারিং ও সেটআপ গাইড দেখুন (docs/diy-breadboard-guide.md)](docs/diy-breadboard-guide.md)**

### প্রয়োজনীয় যন্ত্রাংশ:
1. **ESP32-S3 DevKit** (N8R8 / N16R8 রেকমেন্ডেড)
2. **INMP441** I2S ওমনিডিরেকশনাল মাইক্রোফোন
3. **MAX98357A** I2S অডিও অ্যামপ্লিফায়ার + ৩ ওয়াট স্পিকার
4. **SSD1306** বা **SH1106** I2C OLED ডিসপ্লে (০.৯৬" অথবা ০.৯১")
5. পুশ বাটন (কথা বলা ও সাউন্ড বাড়ানো/কমানোর জন্য)
6. ব্রেডবোর্ড ও জাম্পার ওয়্যার

## সফটওয়্যার ডেভেলপমেন্ট ও ফার্মওয়্যার ফ্ল্যাশ

### প্রয়োজনীয় পরিবেশ
- **ভিজ্যুয়াল স্টুডিও কোড (VS Code)** অথবা **Cursor**
- **ESP-IDF v5.4 বা তদূর্ধ্ব**
- **Python 3.10+**

### ফার্মওয়্যার বিল্ড করার নিয়ম

```bash
# গিট ক্লোন করুন
git clone https://github.com/Eftyqhar/Esp32s3-xiaozhi-ai-voice-assistant.git
cd Esp32s3-xiaozhi-ai-voice-assistant

# ব্রেডবোর্ড ১২৮x৬৪ ওলেড টার্গেটের জন্য বিল্ড করুন
python scripts/release.py --build bread-compact-wifi-128x64

# অথবা সাধারণ esp-idf কমান্ড দিয়ে:
idf.py set-target esp32s3
idf.py build
```

### ফ্ল্যাশ করা
ESP32-S3 বোর্ডটি পিসির সাথে ইউএসবি ক্যাবল দিয়ে সংযুক্ত করে চালান:
```bash
idf.py -p COMx flash monitor
# (উইন্ডোজের ক্ষেত্রে আপনার COM পোর্ট যেমন COM3 বা COM4 দিন, লিনাক্সে /dev/ttyUSB0)
```

## বাংলা ভাষা ও ওলেড ডিসপ্লে (ToBanglish)

কম রেজোলিউশন ও মেমরির ওলেড ডিসপ্লেতে জটিল যুক্তবর্ণ সহজে প্রদর্শনের জন্য এই রিপোজিটরিতে রিয়েল-টাইম বাংলা থেকে বাংলিশ ফনেটিক ট্রান্সলিটারেশন ফিচার যুক্ত করা হয়েছে। এর ফলে এআই-এর বাংলা উত্তরগুলো ডিসপ্লেতে স্পষ্ট ও সাবলীলভাবে ভেসে ওঠে।
